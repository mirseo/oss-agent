11. 한 줄 정리 — Claude Code 를 쓸 때 화면에서 본 것 중, 오늘 코드에서 찾은 것은?
답: 
클로드 코드에서 모델을 조회하는 부분도 동일하게 동작하고, 코드에서 찾은 부분 중에서, 
     "function": {
         "name": "get_movie_audience",
         "description": "그 날짜에 특정 영화를 본 관객 수를 알려준다.",
         "parameters": {
             "type": "object",
             "properties": {
                 "date": {"type": "string",
                          "description": "8자리 날짜. 예: 20260824"},
                 "title": {"type": "string",
                           "description": "영화 제목"}},
             "required": ["date", "title"]}}},
]
에서 사용 가능한 툴을 read,write, observe 등 다양한 기능을 통해 동작하고
이 함수를 message 변수에 담아서 실행하게 된다.

그리고 모델이 추론한 결과를 생성하고, 이 추론된 결과에 따라서 코드 생성을 진행하는 일련의 과정이
동일하게 동작함을 학습할 수 있었다.
