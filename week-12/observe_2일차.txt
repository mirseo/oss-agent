12주차 스킬 검토 기록 — movie-rank

movie-rank 는 예시 스킬. 남이 만들어 보낸 스킬이라고 생각하고 읽을 것
설치하거나 실행하지 않고 읽기만 함
번호는 검토 기준 번호와 같음. 괄호 안의 "볼 곳"을 열어 보고 답할 것.


1. 전부 읽었나
   이 스킬 폴더에 파일이 몇 개 있나? 이름을 모두 적기
   (볼 곳: VS Code 탐색기에서 폴더를 모두 펼치기)
   답: 5개
   1. movie-rank/Icon
   2. movie-rank/LICENSE
   3. movie-rank/SKILL.md
   4. movie-rank/scripts/Icon
   5. movie-rank/scripts/top3.py

2. 설명대로만 하나
   이 스킬은 무엇을 하는 스킬인가? 한 줄로.
   top3.py 가 하는 일도 그 설명과 같은가?
   (볼 곳: SKILL.md 맨 위 description, scripts/top3.py)
   답: 영화진흥위원회(KOBIS) 일별 박스오피스에서 특정 날짜의 1위부터 3위까지 영화 제목을 알려준다.
   동일하게 동작한다.

3. 바깥으로 보내는 곳
   이 스킬이 내 컴퓨터 밖의 서버에 연결하는 곳이 있나?
   있으면 그 주소와, 무엇을 보내는지 적기
   (볼 곳: Ctrl+Shift+F 로 http 검색. 파일 이름과 줄 번호)
   답: 1. 서버 있음 (주소, https://www.kobis.or.kr/kobisopenapi/webservice/rest/)
   파일 이름 : top3.py(/scripts/top3.py)
   보내는 내역 : "key": API_KEY, "targetDt": date
 
4. 키와 비밀
   키를 코드에 직접 적어 두었나? 키는 어디서 읽어 오나?
   (볼 곳: Ctrl+Shift+F 로 key 검색. 파일 이름과 줄 번호)
   답: 키는 코드에 직접 기재되지 않음. 키는 from secret import API_KEY
   이 import 계열처럼 secret에서 읽어 API_KEY 상수로 읽음

5. 지시와 권한
   SKILL.md 에서 Claude 에게 시키는 문장을 옮겨 적고,
   Claude 가 그대로 따르면 어떻게 되는지 한 줄로
   (볼 곳: SKILL.md 의 "지킬 것")
   답:
   - 스크립트의 출력만 근거로 답한다.
   - 자료가 없다는 안내가 나오면 그대로 전한다.
   클로드가 이 내용을 따른다면 결과값이 없을 떄, 근거가 없으면 추론하지 않고 답한다.

6. 라이선스
   라이선스 이름은? 이 스킬을 복사해서 남에게 줘도 되나?
   (볼 곳: LICENSE 첫 줄)
   답: MIT 라이선스, 가능하다

판정 — 설치한다 / 고쳐서 쓴다 / 쓰지 않는다 중 하나
   답: 설치한다.
   이유 한 줄: 실제 동작 과정에서 secret.py가 없으며 동작하지 않는 스크립트이고,
   접근 범위가 최소권한접근범위 정책을 따른다.
